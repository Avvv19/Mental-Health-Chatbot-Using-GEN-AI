# Mental Health Chatbot - Learning Demonstration

This personal learning project explores a retrieval-augmented chatbot using Groq, LangChain, and Hugging Face embeddings. It is a software demonstration, not a mental-health service, crisis resource, diagnostic tool, treatment system, or clinically validated application.

## Boundaries

- Use synthetic or public educational content only.
- Do not enter personal health information.
- Outputs may be incomplete, inaccurate, or inappropriate.
- A qualified professional must make clinical decisions.
- Anyone in immediate danger should contact local emergency services or an appropriate crisis service.

## Project status

The repository demonstrates learning-oriented RAG and conversational application patterns. It has no claimed external users, clinical evaluation, safety certification, production traffic, or healthcare deployment.

## Before reuse

Review the code and dependencies, add a documented data source, create retrieval and safety tests, define escalation behavior, and obtain professional review appropriate to the intended jurisdiction and use case.
